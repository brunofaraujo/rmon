Como ler esta tela
A comparação acontece dentro de um ambiente: {{ ambiente_label or 'o parque' }} tem {{ servidores|length }} servidor(es), e a referência de "atualizado" é a maior versão encontrada entre eles · versões diferentes = os servidores não estão todos na mesma versão · falta = não está em algum servidor do mesmo papel (a camada web não tem o mesmo software que a de aplicação, e isso não conta como falta) · Disponível = maior versão já baixada do TDN para aquele item ({{ resumo.catalogo }} pacote(s) no repositório{% if resumo.sem_vinculo %}, {{ resumo.sem_vinculo }} sem item vinculado{% endif %}) · * na data = estimada pela primeira coleta do RMon (o registro do Windows não informa a data) · ↻ no cartão do servidor = última atualização aplicada pelo RM.Atualizador.
